Sincronizar com a Cardápio Web

Opcional. Puxa os insumos cadastrados na Cardápio Web (nome, unidade, categoria e custo) para dentro do NotaFlow. O saldo daqui nunca é alterado pela sincronização, e nada é enviado de volta para lá.

Baixa automática pelas vendas

O NotaFlow consulta os pedidos da Cardápio Web a cada 30 segundos e dá baixa no estoque quando o pedido é confirmado. Pedido cancelado devolve o saldo. Cada produto é ligado ao insumo pelo código (código externo no cardápio = código do insumo) ou, se não houver código, pelo mesmo nome.
